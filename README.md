# Thirupathi Rao Murala — Developer Portfolio

Personal portfolio site built with **Angular 18** (standalone components).

Backend-first full-stack developer (Java · Spring Boot · Angular) with production AI experience.

## Tech
- Angular 18, TypeScript, standalone components
- Responsive, dark theme, zero external runtime dependencies

## Run locally
```bash
npm install
ng serve
# open http://localhost:4200
```

## Build
```bash
ng build
# output: dist/portfolio/browser
```

## Deploy
Hosted on GitHub Pages (`https://murala-thirupathi.github.io/`) and Netlify.
